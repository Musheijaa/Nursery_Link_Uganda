# Nursery Link Uganda

A Web-GIS marketplace and supply-gap analytics platform for Uganda's tree nursery sector.

Nursery Link Uganda replaces the paper logbooks and scattered spreadsheets currently used to track tree nurseries with a single coordinate-accurate platform. Buyers, restoration planners, and carbon-project developers can browse a live map of certified nurseries, check real-time seedling stock, and check out delivery orders with mobile money escrow. An admin-side "Nursery Shadow" engine overlays road-network service zones against satellite forest-loss data to flag underserved, heavily deforested areas — surfacing where new nurseries or funding are needed most. The platform also hosts a directory of free seedling giveaways from government, NGO, and corporate funders, and a Digital Tree Library for species reference.

**Key features**
- Interactive nursery map with district/sub-county filtering and live inventory
- Order & Deliver checkout with distance-based pricing and mobile money escrow (MTN MoMo / Airtel Money)
- Nursery Shadow analysis: road-network service zones (5/10/20 km) overlaid on Global Forest Change data
- Free seedling campaign directory with eligibility rules
- Digital Tree Library cross-linked to nursery inventory

**Stack:** React · Node.js/Express · PostgreSQL + PostGIS · Leaflet · MTN MoMo/Airtel Money API
